# Сайт-визитка

**Живой сайт:** https://justoneanotherprogger.github.io

Персональный сайт-визитка на Python + Jinja2, развёрнутый на GitHub Pages.

Минималистичный сайт-визитка с тёмной темой. Включает разделы "Обо мне" и "Мои проекты".

## Технологии

- **Python 3.11** — генерация статики через Jinja2
- **Jinja2** — шаблонизация HTML
- **GitHub Actions** — автоматический деплой на GitHub Pages
- **HTML/CSS/JS** — фронтенд без фреймворков
