# Сайт-визитка

Персональный сайт-визитка на Python + Jinja2, развёрнутый на GitHub Pages.

## О проекте

Минималистичный сайт-визитка с тёмной темой. Включает разделы "Обо мне" и "Мои проекты".

## Технологии

- **Python 3.11** — генерация статики через Jinja2
- **Jinja2** — шаблонизация HTML
- **GitHub Actions** — автоматический деплой на GitHub Pages
- **HTML/CSS/JS** — фронтенд без фреймворков

## Локальный запуск

```bash
pip install jinja2
python build.py              # генерирует index.html
# открыть index.html в браузере
```

## Деплой

Пуш в `main` запускает GitHub Actions, который генерирует статику и деплоит на GitHub Pages.

## Контент

Все данные (проекты, соцсети, тексты, теги) хранятся в `data/projects.py`. Для обновления контента — редактируй этот файл и перезапускай `build.py`.
