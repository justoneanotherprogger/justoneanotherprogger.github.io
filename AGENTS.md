# AGENTS.md

Инструкции для ИИ-агентов, работающих в этом репозитории. Загружаются автоматически при сканировании проекта.

## Проект

Персональный сайт-визитка: Python + Jinja2 генерирует статику, GitHub Actions деплоит её на GitHub Pages при каждом push в `master`. Сгенерированный HTML не хранится в репозитории — только источники.

## Структура

- `data/projects.py` — весь содержательный контент (тексты, проекты, соцсети) как Python-модуль
- `templates/` — Jinja2-шаблоны страниц
- `static/` — CSS, шрифты, картинки (фронтенд без фреймворков)
- `build.py` — генерация HTML из `data/` + `templates/`

## Как менять

- Тексты и содержимое разделов — только в `data/projects.py`
- Разметка и оформление страниц — в `templates/`, общие стили — `static/css/`
- Локальная проверка: `python build.py` и просмотр собранного HTML; в репо его не коммитить
- Основная ветка — `master`; изменения через ветки и PR

## Осознанные решения

- Рэтчет размеров файлов здесь не применяется: исходники малы и статичны, бинарные шрифты строками не меряются.
